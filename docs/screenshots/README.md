# Screenshots

Full-page captures of every page at 1440 px (desktop) and 390 px (phone) in dark mode, written by `npm run screenshots` after `npm run build`. The `-desktop` and `-phone` suffixes name the viewport. The e2e suite also captures both widths in light mode (`-light` suffix) under `e2e/screenshots/`, which is not committed to keep the repository small; the before-and-after set from the UI pass is summarised in [`../UI-PASS.md`](../UI-PASS.md).
